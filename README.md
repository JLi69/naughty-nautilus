# Naughty Nautilus

This is my entry to the 2026 Game Dev Club Club Jam Jam. The theme was "shell",
and you know what has shells? Nautiluses! (Nautili?)

In this game, you play as a Nautilus and you ram into fish that are trying
to eat you. It's a fairly simple game but personally I think it's quite fun
so if you want to try it out, you can play/download it on
[itch.io](https://nullptr-error.itch.io/naughty-nautilus).
